### 3. 原有人工繁育的野生动物情况说明材料

| 字段 | 内容 |
| --- | --- |
| 材料必要性 | 非必要 |
| 材料类型 | 原件 |
| 材料形式 | 纸质或电子 |
| 来源渠道 | 申请人自备 |
| 来源说明 | 无 |
| 材料要求 | 真实合法，A4纸 |
| 受理标准 | 1.材料要真实合法。<br>2.野生动物人工繁育、经营利用单位和个人须建立人工繁育经营利用管理台账。<br>3.原有人工繁育的野生动物种类、数量和健康状况的说明材料 |
| 填报须知 | “已经取得的人工繁育许可证和相关批准文件”可通过内部工作流程方式获取或通过信息共享核实，无需申请人提供。 |
| 材料依据 | 根据《中华人民共和国野生动物保护法》第二十五条国家支持有关科学研究机构因物种保护目的人工繁育国家重点保护野生动物。<br>前款规定以外的人工繁育国家重点保护野生动物实行许可制度。人工繁育国家重点保护野生动物的，应当经省、自治区、直辖市人民政府野生动物保护主管部门批准，取得人工繁育许可证，但国务院对批准机关另有规定的除外。<br>人工繁育国家重点保护野生动物应当使用人工繁育子代种源，建立物种系谱、繁育档案和个体数据。因物种保护目的确需采用野外种源的，适用本法第二十一条和第二十三条的规定。<br>本法所称人工繁育子代，是指人工控制条件下繁殖出生的子代个体且其亲本也在人工控制条件下出生。<br>第二十六条人工繁育国家重点保护野生动物应当有利于物种保护及其科学研究，不得破坏野外种群资源，并根据野生动物习性确保其具有必要的活动空间和生息繁衍、卫生健康条件，具备与其繁育目的、种类、发展规模相适应的场所、设施、技术，符合有关技术标准和防疫要求，不得虐待野生动物。<br>省级以上人民政府野生动物保护主管部门可以根据保护国家重点保护野生动物的需要，组织开展国家重点保护野生动物放归野外环境工作。 |
| 纸质材料规格 | 无 |

### 办理流程说明

1. 申请人通过“安徽政务服务网“、邮寄或到省政务服务中心综合窗口提交申请材料；
2. 窗口工作人员在“安徽政务服务网”网上或现场审核申请材料，材料合格，予以受理；
3. 窗口首席代表对申请材料进行复核，在承诺办结时限内作出准予或不予行政许可的决定；
4. 窗口工作人员根据窗口首席代表的意见进行办结，制作结果文件；
5. 申请人员现场领取结果文件或由窗口工作人员邮寄送达。
