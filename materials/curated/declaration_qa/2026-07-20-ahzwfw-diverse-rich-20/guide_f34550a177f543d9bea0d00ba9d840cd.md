## 办理条件

1.申请材料齐全，符合法定形式。
2.市场主体实行实名登记。申请人应当配合登记机关核验身份信息。

## 申请材料

### 1. 企业注销登记申请书（普通程序）

| 字段 | 内容 |
| --- | --- |
| 材料必要性 | 必要 |
| 材料类型 | 原件 |
| 材料形式 | 纸质或电子 |
| 来源渠道 | 申请人自备 |
| 来源说明 | 无 |
| 材料要求 | 1份 |
| 受理标准 | 按示例表格填写。<br>在登记机关现场办理实名登记确认的，需提交《实名登记确认表》。<br>已领取纸质版营业执照的，缴回营业执照正、副本。拒不缴回或无法缴回营业执照的，由登记机关通过国家企业信用信息公示系统公告营业执照作废。 |
| 填报须知 | 1.通过国家企业信用信息公示系统公示解散事由、公告清算组。公告期不少于45日。<br>2.按示例表格填写。在登记机关现场办理实名登记确认的，需提交《实名登记确认表》。<br>已领取纸质版营业执照的，缴回营业执照正、副本。拒不缴回或无法缴回营业执照的，由登记机关通过国家企业信用信息公示系统公告营业执照作废。 |
| 材料依据 | 《中华人民共和国市场主体登记管理条例实施细则》 第四十六条 申请办理注销登记，应当提交下列材料：<br>（一）申请书；<br>（二）依法作出解散、注销的决议或者决定，或者被行政机关吊销营业执照、责令关闭、撤销的文件；<br>（三）清算报告、负责清理债权债务的文件或者清理债务完结的证明；<br>（四）税务部门出具的清税证明。<br>除前款规定外，人民法院指定清算人、破产管理人进行清算的，应当提交人民法院指定证明；合伙企业分支机构申请注销登记，还应当提交全体合伙人签署的注销分支机构决定书。<br>个体工商户申请注销登记的，无需提交第二项、第三项材料；因合并、分立而申请市场主体注销登记的，无需提交第三项材料。<br>第四十七条 申请办理简易注销登记，应当提交申请书和全体投资人承诺书。<br>《市场监管总局关于印发经营主体登记文书规范和提交材料规范（2026年版）的通知》。 |

## 常见问题

### Q1: 公司注销后，被列入黑名单的公司法定代表人能否移除？

公司注销后，企业主体注销，涉企信息完结，原公司法定代表人不再列入黑名单。

### Q2: 分公司注销影响总公司经营吗?

分公司注销，只是公司的一个分支机构注销，公司正常存在，依法经营，没有影响。

### Q3: 不注销分公司只注销总公司可以吗?

分公司不具有法人资格，不能独立承担民事责任，应由总公司承担民事责任。因此，应当先注销分公司，再注销总公司。
