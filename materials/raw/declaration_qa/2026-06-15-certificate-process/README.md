# Declaration QA Certificate Online Process Materials (2026-06-15)

This directory contains raw official webpages for citizen certificate/proof handling workflows, aligned to the declaration QA use case.

Examples covered:

- health certificate / electronic health certificate
- residence permit online application
- resident ID card online replacement/reissue
- temporary resident ID card
- no-criminal-record proof via Wanshitong
- disabled person card workflows
- teacher qualification certificate recognition
- birth medical certificate reissue
- vaccination check certificate for kindergarten/school enrollment
- Hong Kong, Macao, and Taiwan resident residence card

These are raw crawl artifacts only. They have not been imported into the running knowledge base.

For each document, see:

- `source.html`: original fetched page
- `content.md`: extracted text for review
- `metadata.json`: source URL, hashes, region, certificate type, and crawl status
